# Security reports

Report vulnerabilities privately through the repository's Security tab using
GitHub private vulnerability reporting. Include the affected version, platform,
reproduction and expected boundary. Avoid credentials or private task content.

This harness executes agents admitted by its controlling application; it is not
a sandbox. The application owns authorization, executable and tool admission,
credentials and durable state. Tasks/control frames cannot override trusted
launch configuration. See the security specification for the supported boundary.
